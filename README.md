# IBM-SpaceX-Capstone-Project
IBM Data Science Capstone Project – SpaceX Launch Analysis &amp; Dashboard

## Overview

This project is part of the IBM Data Science Professional Certificate Capstone Project.

The objective of this project is to analyze SpaceX launch data and build a machine learning model to predict the success of Falcon 9 first-stage landings. The project also includes data collection, data wrangling, exploratory data analysis, SQL analysis, interactive visualizations, and a Plotly Dash dashboard.

## Project Objectives

- Collect SpaceX launch data using APIs and web scraping.
- Clean and prepare the data for analysis.
- Perform exploratory data analysis using Python and SQL.
- Visualize launch sites and launch outcomes.
- Build an interactive Plotly Dash dashboard.
- Train and compare machine learning classification models.

## Project Components

### Data Collection
SpaceX launch data was collected using APIs and web scraping.

### Data Wrangling
The collected data was cleaned and transformed using Pandas.

### Exploratory Data Analysis
Python visualizations and SQL queries were used to analyze SpaceX launch data.

### Interactive Dashboard
A Plotly Dash dashboard was created to visualize launch sites, payload mass, booster versions, and landing outcomes.

### Machine Learning
Classification models were trained to predict first-stage landing success.

The models include:

- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)

## Repository Contents

This repository contains the notebooks, Python files, datasets, and other files used for the SpaceX Capstone Project.

## Conclusion

The project provides insights into SpaceX launch patterns and first-stage landing success using data analysis, visualization, dashboards, and machine learning.
